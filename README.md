> Interactive movie discovery web application highlighting blockbuster titles, synopsis breakdowns, ratings, and genre-based movie showcases.

---

## 🍿 Features

- **Featured Blockbuster Showcase:** Dynamic hero spotlights for trending theatrical releases.
- **Movie Profile Detail Pages:** High-resolution movie posters, plot synopsis, cast lists, and runtimes.
- **Categorized Catalogs:** Action, Thriller, Sci-Fi, and Comedy streaming cards with smooth hover animations.
- **Mobile Friendly:** Fully responsive flexbox/grid layout.
